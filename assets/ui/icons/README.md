# Silica Street UI icons

Generate with:

```bash
python3 tools/generate_ui_icons.py
```

The first set contains resource, service, season and diagnostic symbols required by the playable benchmark. Icons use a shared 64×64 view box and communicate status through silhouette plus colour. They are source SVGs intended for Godot import; raster sizes should be generated by the engine/import pipeline rather than committed manually.

Coral is reserved for actionable failures, amber for waiting/attention, cyan for ordinary flow/information, green for biological provision and grey for unavailable/dormant states.
