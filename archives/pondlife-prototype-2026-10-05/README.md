# Original Pondlife prototype archive

Archived at Rich's request on 5 October 2026. The bundle contains the complete Git history and the final local changes, committed as `73df57bd6e4f25105f1ef9684c82c7b2a60acb72` on `master`. The original `pondlife/game` checkout remains available and clean. This archive is separate from the active v2 game.

Restore into a new directory:

```sh
git clone archives/pondlife-prototype-2026-10-05/prototype.bundle pondlife-prototype
```

Verify the archive:

```sh
git bundle verify archives/pondlife-prototype-2026-10-05/prototype.bundle
```

This is a preservation snapshot. The old prototype's final gameplay changes were not newly playtested as part of the repository sync. Generated Godot caches and ignored local files are excluded by the original repository's rules.
