# Pondlife — first submerged neighbourhood

Owner: Codex, project lead at Rich's request. Revised 6 October 2026 after Rich rejected land-based roads and a redundant river. Read [the design foundation](design/README.md) and [brief/reference audit](BRIEF_REFERENCE_AUDIT_2026-10-06.md).

## The intended experience

Establish an empty underwater habitat using a funded, paid opening. Grow controlled-current lanes; attach every building's intake; cultivate feedstock, process food and minerals, observe cargo travelling to local depots, supply genuinely local services, and evolve a home. The world must explain those relationships at normal gameplay zoom.

## Acceptance gates

1. Start paused with no prebuilt settlement, lanes or carriers. Starter supplies and off-map founders provide a legal opening; placement/cancellation remains under player control.
2. Every building joins the same connected current network through a visible intake branch. Ghosts validate authoritative geometry, habitat and connection rules. Rotation, curves, snapping, cancellation, context actions and zoom remain usable.
3. The surrounding liquid is habitat, not a placement barrier. Remove surface-river rendering and dry-bank decoration. Any future flow hazard must have inspectable rules and an ecological purpose before it excludes construction.
4. Production geography matters. Light affects photosynthetic fields; published mineral exposures constrain extraction. Terrain/overlays show the same data the simulation uses.
5. Real finite carriers display actual cargo and move supplies between the anchor and local depots. Inputs, outputs, construction and home provisions obey delivery time and conservation. Pausing freezes authoritative traffic.
6. Services have measured network reach. Placement and inspection explain which homes are covered and why. Moving a provider changes the result. Organic home growth follows satisfied needs.
7. A legal opening houses the founders, establishes food, completes the raw-to-refined chain, reaches a Stable home, and survives the first environmental cycle. Record commands and bounded evidence; do not generalise one opening into long-game balance.
8. Test the normal-renderer native game with the icon UI. Technical regression, independent review and Rich's visual judgement are separate gates. Fix critical interaction defects before release.

## Current limits

This neighbourhood is the next proof, not the full Chemical Civilisation GDD. Specialised stores and direct depot-to-depot routes, spatial upkeep/trade/research/Great Work, save persistence, flexible cultivation plots, richer environmental hazards, rival settlements and Memory Reef completion remain separate work. Disclose those limits; never replace missing gameplay with decorative animation.
