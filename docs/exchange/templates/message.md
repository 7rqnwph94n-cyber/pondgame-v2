## Context

Why this message exists, in one or two sentences.

## Changed

Files, schemas, interfaces or assets changed (repository-relative paths, commit if known). "None" for a request-only message.

## Decision/evidence

Facts, numbers and decisions, kept separate. When relaying Rich, quote him verbatim and label your interpretation.

## Action requested

Exact response or work needed from each recipient, and acceptance criteria. "None" for information only.

## Compatibility/risk

What the recipient must not break, and what may need migrating.

## Reference

Commands, files, branches, commits, earlier message ids.
